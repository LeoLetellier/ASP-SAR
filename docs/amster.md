# AMSTer helpers


## Geocode files

::: am_geocode

Can bulk geocode rasters of same size than the AMSTer product, either by giving the path of a possibly multiband raster, or the path to a file with one single band raster by line.

## Convert AMSTer raster to GTiff

::: amster2tiff

Auto-fetch AMSTer raster size and open as numpy from file.
