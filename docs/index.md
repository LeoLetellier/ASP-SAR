# ASP-SAR: SAR Correlation Toolkit

Repertory of shell and python scripts for handling SAR data. The first aim is to bridge and combine usage from AMSTer, NSBAS, and ASP softwares, mostly for performing SAR image correlation (pixel tracking).

Check the related pages:

- for the [pixel tracking workflows](workflow)
- for [helpers function for AMSTer](amster)
- for [helpers to handle pair network](network)
- for [various plotting scripts](plots)
- for [various raster processing](raster)
